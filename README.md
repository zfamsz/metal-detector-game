# Metal Detector — Cari Harta Karun

Game web (HTML/CSS/JS, tanpa install). Sapu detektor di lapangan, ikuti bip sinyal, gali harta sebelum waktu habis.

- 🪙 Koin +10 | 🥇 Emas +25 | 💎 Permata +50 | 🔩 Sampah +0
- Ronde 60 detik, harta makin banyak tiap ronde
- Skor terbaik tersimpan di browser (localStorage)

Main: https://zfamsz.github.io/metal-detector-game/
